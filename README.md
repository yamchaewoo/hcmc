# hcmc — 한/글 매크로 액션 사전

한/글(HWP) COM 매크로를 쓸 때 필요한 **액션 ID와 파라미터 사전**입니다.
설치된 한/글에서 기계적으로 추출하고 실제로 실행해 검증했습니다. 손으로 기록하거나 추측한 내용이 아닙니다.

기준 버전: **한글 13.0.0.3379 (한글 2024)**

## 왜 필요한가

한/글 매크로는 문법 자체는 평범하지만, 쓰는 어휘(액션 ID, 파라미터 이름)가 완전히 독자적입니다.
그래서 LLM에게 그냥 "한글 매크로 짜줘"라고 하면 그럴듯하지만 **존재하지 않는 액션 ID**를 만들어냅니다.
이 저장소는 그 어휘집을 제공해서, 매번 사람이 동작을 하나씩 기록하지 않아도 되게 합니다.

## Claude와 함께 쓰는 법

### Claude Code

저장소를 클론한 폴더에서 Claude Code를 실행하면 `CLAUDE.md`를 자동으로 읽습니다. 바로 시키면 됩니다.

```
git clone https://github.com/yamchaewoo/hcmc.git
cd hcmc
claude
```

> "선택한 문단을 전부 가운데 정렬하고 각 문단 끝에 미주를 다는 매크로 만들어줘"

### 웹/앱 Claude

대화창에 **`CLAUDE.md`와 `한글매크로_액션사전.md` 두 개를 첨부**하고 요청하세요.
`hwp_macro_dict.json`은 크니(330KB) 표에 없는 액션의 파라미터가 필요할 때만 같이 올리면 됩니다.

## 어떻게 만들었나

추측이 섞이지 않도록 각 단계를 검증 가능하게 했습니다.

1. **후보 추출** — `HwpApp.dll`, `Hwp.exe` 등에서 액션 ID 형태의 문자열 61,140개를 뽑음
2. **전수 검증** — 설치된 한/글에 `CreateAction()`으로 하나씩 물어봄. 없는 ID는 `None`을 돌려주므로 확실히 걸러짐 → **1,807개 확정**
3. **파라미터 매핑** — 검증된 액션의 `.SetID`로 파라미터셋 이름을 얻고, 타입라이브러리 덤프에서 인자 목록과 자료형을 연결 (137개 중 136개 매칭)
4. **한글 라벨** — 한/글 공식 도움말의 단축키표(365행)에서 기능명·단축키를 가져와 액션 ID와 연결. **라벨링 스크립트가 모든 ID의 실존을 자동 검증**하므로 없는 ID는 표에 들어갈 수 없음
5. **동작 실측** — 실제로 한/글을 띄워 실행하고 결과 확인 (미주 넣으면 개체목록에 `en` 생성, 표 만들면 `tbl` 생성, `BreakPara`는 문단번호 증가 / `BreakLine`은 유지 등)

## 라이선스와 범위

사전 데이터는 사용자 PC에 설치된 한/글에서 추출한 **사실 정보**(액션 이름, 파라미터 이름, 단축키)입니다.
한컴의 도움말 문서 원본이나 프로그램 바이너리는 포함하지 않습니다.
